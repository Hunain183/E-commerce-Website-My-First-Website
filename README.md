# E-commerce-Website-My-First-Website

A responsive e-commerce website built with HTML, CSS, and JavaScript featuring product catalogs, shopping cart functionality, and a clean professional structure.

## 🚀 Features

- Responsive design that works on all screen sizes
- Multiple product categories (Beauty, Electronics, Toys, Sports, Accessories)
- Shopping cart with localStorage persistence
- Product search and sorting functionality
- Modern UI with smooth animations
- Bootstrap integration for enhanced styling

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with Flexbox and Grid
- **JavaScript (ES6+)** - Interactive features
- **Bootstrap** - Responsive framework
- **LocalStorage API** - Client-side cart persistence
- **PHP** - Backend functionality (user auth, database)

## 🚦 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Hunain183/E-commerce-Website-My-First-Website.git
   ```

2. Navigate to the project directory:
   ```bash
   cd E-commerce-Website-My-First-Website
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   python3 -m http.server 8000
   ```

4. Visit `http://localhost:8000` in your browser

## 📱 Responsive Design

The website is fully responsive and adapts to:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)

## 🛒 Features

### Product Browsing
- Browse products by category from the navigation menu
- Use the search bar to find specific items
- Sort products by price or name

### Shopping Cart
- Add items to cart from any product page
- View cart summary on hover
- Manage quantities and remove items in the cart page
- Cart persists across browser sessions

### User Account
- Sign up for a new account
- Form validation for user inputs
- PHP backend integration for authentication
